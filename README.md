# 🤖 Local SLM Chatbot

A fully local, privacy-focused conversational AI agent built with **LangGraph**, **LangChain**, and **Streamlit**, powered by **Ollama**. 

This application uses a local Small Language Model (SLM) to generate responses, meaning no API keys are required and no chat data ever leaves your machine.

## 🚀 Features

* **100% Local Execution:** Powered by Ollama, ensuring complete privacy and offline capabilities.
* **LangGraph Orchestration:** Utilizes a stateful graph architecture (`StateGraph` and `MessagesState`) to manage conversation memory and flow.
* **Streamlit Interface:** A clean, responsive, and easy-to-use web interface for chatting.

## 📋 Prerequisites

Before you begin, ensure you have the following installed on your machine:
1. **Python 3.10+**
2. **Ollama:** Download and install from [ollama.com](https://ollama.com/)
